# QR Code Generator

A simple, modern, and responsive QR Code Generator with a futuristic multiverse-inspired design.

## Features

- Generate QR Code: Create a QR code from any text or URL.
- Download QR Code: Download your generated QR code.
- Clear: Clear the input and generated QR code.
- Live Clock: Displays the current date and time.
- Daily Quotes: Displays motivational quotes that change daily.
- Spider-Web Animation: Features a unique web-weaving animation around the generated QR code.
- Responsive Design: Works on desktop and mobile devices.
- Custom Favicon: Includes a custom browser tab icon.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- QRCode.js

## How to Use

1. Open the QR Code Generator website.
2. Enter your text or URL in the input field.
3. Click Generate to create your QR code.
4. Click Download QR to save the generated QR code.
5. Click Clear to remove the current QR code and start again.

## Deployment

This project can be hosted for free using GitHub Pages.

1. Upload the project files to your GitHub repository.
2. Go to Settings → Pages.
3. Select the `main` branch and `/ (root)` folder.
4. Click Save.
5. Your website will be published using GitHub Pages.
